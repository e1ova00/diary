# ❄ Снежный забег ПДД

3D-игра для подготовки к экзамену ПДД (билеты категорий A, B, M).

Зимний лес, замёрзшая река и 26 островов — по одному на каждую тему билетов.
Мальчик в шапке с помпоном бегает и прыгает по льдинам от острова к острову
(темы можно перепрыгивать в любом порядке), за ним бегут трое друзей.
У каждого острова — светящиеся ворота: внутри темы мини-темы по 5 вопросов.

- **800 вопросов** из всех 40 билетов, разбитых на 26 тем и 173 мини-темы.
- **Оригинальные картинки** к вопросам, ответы и пояснения со ссылками на пункты ПДД — из базы билетов [drom.ru/pdd](https://www.drom.ru/pdd/).
- **Очки** ❄ за верные ответы и бонус за серию 🔥.
- Мини-тема пройдена (не больше одной ошибки) — **мини-танец** с конфетти и музыкой.
- Без ошибок, вся тема целиком или сданный экзамен — **большой танец с друзьями**.
- ❗ **Работа над ошибками** — неверные ответы копятся и уходят, когда ответишь правильно.
- 🎓 **Экзамен** — 20 случайных вопросов, можно ошибиться не больше двух раз.
- Вокруг — дорога с машинками, светофор, пешеходный переход (мальчик переходит на зелёный), дорожные знаки, ребята со снеговиком.
- Прогресс сохраняется в браузере (localStorage).

## Управление

| Компьютер | Телефон |
|---|---|
| WASD / стрелки — бег | джойстик слева |
| Пробел — прыжок | кнопка ⤒ |
| E / Enter — открыть тему у ворот | кнопка ✋ |
| мышь (зажать и тянуть), колёсико — камера | провести пальцем по правой части экрана |
| 1–5 — выбрать ответ, Enter — дальше | касание |

## Как запустить

Игра — статический сайт без сборки, но из-за ES-модулей её нужно открывать через веб-сервер,
а не двойным кликом по файлу:

```bash
cd game
python3 -m http.server 8000
# открыть http://localhost:8000
```

Или включить GitHub Pages для репозитория (ветка, папка `/`) — корневой `index.html` перенаправит в `game/`.

## Устройство

- `game/index.html`, `game/style.css` — интерфейс.
- `game/js/main.js` — игровой цикл, физика прыжков, камера, управление, танцы, снег и конфетти.
- `game/js/world.js` — мир: река, острова и льдины, ёлки, дорога, машинки, светофор, знаки.
- `game/js/boy.js` — низкополигональный мальчик и процедурные анимации (бег, прыжок, 5 танцев: присядка, флосс, вертушка, диско, прыжки-хлопки).
- `game/js/quiz.js` — мини-темы, вопросы, очки, прогресс, работа над ошибками, экзамен.
- `game/js/audio.js` — звуки и танцевальная мелодия на WebAudio.
- `game/questions.js` — вопросы, ответы и пояснения; `game/img/` — картинки к вопросам.
- `game/vendor/three.module.min.js` — three.js r169 (MIT).
