# Грязнулька или чистюлька?

Мем-тест на 18 вопросов по тренду из TikTok: сколько в тебе грязнульки, чистюльки и ШБ.
Отдельные вопросы и цвета для девочек (розовый) и мальчиков (синий).

Запуск: открыть `index.html` в браузере. Сборка не нужна.
Хостинг: Settings → Pages → Deploy from branch → корень ветки.

## Интро-мультик
3D-сцена на Three.js (vendor/three.min.js). Чтобы играл свой трек, положи `music/dynasty.mp3` — он прозвучит ускоренным и писклявым. Без файла играет встроенный синтезированный бит. Настройки — в начале `intro.js`.
